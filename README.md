# Novak para Windows

Ventana propia para [Novak](https://novak-app.vercel.app), con las notificaciones de Windows.

## Descargar

**[Descargar Novak para Windows](https://github.com/webloomwebs/novak-desktop/releases/latest/download/Novak-Setup.exe)**

Se abre el archivo y se instala solo. No pide permisos de administrador.

La app vive en la web, asi que se actualiza sola: no hay que volver a instalarla cuando salga algo nuevo.
