# Novak para Windows

Ventana propia para [Novak](https://novak-app.vercel.app), con las notificaciones de Windows.

## Descargar

**[Descargar Novak para Windows](https://github.com/webloomwebs/novak-desktop/releases/latest/download/Novak-Setup.exe)**

Al abrirlo, Windows dira **«Windows protegio su PC»**. Es lo que hace con cualquier programa que no
venga de una empresa que ya conozca, y este lo hemos hecho nosotros:

1. **Mas informacion**
2. **Ejecutar de todas formas**

Se instala solo, sin pedir permisos de administrador. Tarda unos segundos y se abre.

Si Chrome avisa al descargar («no se descarga habitualmente»), es lo mismo: **Conservar**.

## Actualizaciones

La app vive en la web, asi que se actualiza sola. No hay que volver a instalarla.
